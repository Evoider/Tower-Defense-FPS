# Tower Defense FPS — Game Jam (4 days)

Prototype built in 4 days with a classmate as part of
a school game jam.

Concept: first-person tower defense — the player defend his towers with some abilities from waves of enemies

## Context
- Engine: Unreal Engine
- Team: 2 developers
- Duration: 4 days

## What I Built
- Created the wave system as well as the game Loop
- Parts of the enemy behaviors and customized one of the enemy with a special skill
- The main menu
- some of the maps
- Delivered a playable prototype under tight time constraints
- Collaborated using version control in a 2-person team

## Stack
Unreal Engine · Blueprints / C++ · Git
